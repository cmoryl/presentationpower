# Design Set 5 reusable asset library

## Deliverable
Create a separate **San Juan Bowl — Design Set 5 Assets** Canva folder and a downloadable asset pack for use outside Element. Existing campaign designs remain unchanged.

## Artwork
- Inventory all Set 5 formats and deduplicate their original backgrounds, retaining source-resolution copies as references.
- Rebuild matching independent football, palm, lighting, texture and motion elements instead of pretending the flattened originals contain recoverable layers. Label these as new matching artwork.
- Use transparent PNGs for movable photographic-style objects and overlays. Build graphic slashes, rules and halftone patterns as scalable SVG artwork where practical.
- Keep approved Bowl and conference logos separate and unchanged; reuse available official vector masters rather than regenerate them.
- Assemble editable layered wide, portrait and tall compositions with clean content space. Include standalone pieces so designers can reposition them in other software.

## Resolution and delivery
- Generate raster pieces at the highest supported native resolution; include clearly labelled enlarged copies only when useful. Enlargement does not create genuine source detail.
- Supply self-contained layered SVG compositions, individual SVG/PNG assets, preview sheets and a ZIP with a source/resolution manifest. Do not call raster-containing SVGs fully vector.
- Organize Canva into Original references, Rebuilt backgrounds, Transparent pieces and Layered compositions. Verify folder contents and exports.
- Review transparency edges, proportional placement and every rebuilt asset. Preserve RGB; no silent CMYK conversion.

## Production boundary
There is no universal resolution for “massive signage.” The pack will support flexible composition, but final print readiness still depends on the chosen physical size, viewing distance and vendor specification. Canva's layer-separation feature is not proof of recovered original layers or increased resolution.

## Technical details
Use the existing Set 5 gallery registry for inventory only. Keep reusable compositions independent of live campaign renderers. Embed all linked imagery in portable SVG deliverables; record native dimensions and distinguish original, rebuilt and enlarged files in the manifest.
