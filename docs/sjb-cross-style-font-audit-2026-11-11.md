## Findings
- **Confirmed mismatch across Dark, Light and Set 3:** 141 missing-picture slots render Barlow Condensed instead of the recorded native Heading Now face. This affects calendar demos and their downloadable drawn covers, not the font in an uninspected Canva original.
- **Saved Set 2/3/4 pictures:** no obvious new face substitution visible within their reviewed native campaign groups. Exact font identity is not certified from raster pictures.
- **Dark native campaign:** saved lettering is visibly broader than Sets 2/3/4. It remains consistent with existing Dark source pictures, but the previously requested narrow Set 2-style Dark rebuild is still outstanding.
- **Light:** saved examples preserve italic main headlines with upright secondary lines. Square/Story line sizes and prominence differ from some Feed originals; font family and layout hierarchy must not be confused.
- **Sequence companions, all looks:** main callouts use Barlow; details/supporting copy uses Geist. These remain demos, not original-font Canva pages. Light ticket/website/broadcaster companion headings lose its italic treatment.
- **Scale/readability:** font size and footer prominence are inconsistent across originals; the approved callout-enlargement rollout is unfinished. That is separate from identifying typeface substitution.
- CBS Sports Network lettering is supplied artwork and excluded from headline-font matching.
