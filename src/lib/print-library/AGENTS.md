# Print library

- Curated print pieces with a supplied PDF render in "Original layout" (`content.layoutMode/original`, data from `scripts/lifesci-original-extract.py` → `src/lib/print-library/lifesci-original-layouts.json`, drawn by `OriginalPageLayout`); the library-layout fields stay in the same content — why: page-for-page fidelity while the cascade keeps reading the structured copy.
- Print library Company / Product filters read `src/lib/print-library/item-tags.ts` (entry's own `company`/`product`, else names it carries, else "Not tagged") — why: one tagging rule for the library and the admin catalogue, never guessed.
- Original-layout artwork is split into separate pieces by `scripts/lifesci-original-pieces.py` (MuPDF SVG → per-object vector SVGs in paint order; pieces MuPDF's SVG misdraws are flattened from MuPDF's own render) into `pages[].pieces`; saved copies without pieces are upgraded at render by `withPieces` via `legacyGround` — why: every part of a supplied file is movable/resizable/tintable/hideable without breaking existing copies.
- Original-layout pieces feed social, print sizes and slides from the editor's own visible text (`editorCopyFromOriginal`, read by `print-cascade.ts` `contentOf`), and `/convert` applies the saved master override; editor edits also rewrite matching library fields (`syncCopyFromOriginal`) — why: every format must read what the editor shows.
