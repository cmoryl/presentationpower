4. Format reference

Layout logic, dimensions, and per-division vs. shared-copy notes for each of the 28 formats referenced by number in section 4. Format 1 is the sponsorship packet; format 2 is the PowerPoint template; formats 3–16 are the original square/LinkedIn/email-header campaign (with format 8 the dark-callouts LinkedIn post next to its light counterpart at format 7); formats 17–28 are the advocacy-square and speaker-card campaign.

3. Square post (1200×1200)

Media is the only division with a character/hero image (an armored figure, top-right, roughly 723×887px). Decision made to skip sourcing character images for the other 10 divisions.

4. LinkedIn single-image ad — navy (1200×627)

Fixed 2026-07-08: the source template's big background circle was originally a fixed, non-editable shape — it always rendered green (Games' color) regardless of division. The Games source file was manually converted in Canva's UI into a real image frame, producing a new circular element that defaults to Games' accent color. All 10 other divisions were rebuilt fresh from this fixed source with the new circle set to each division's own accent color, alongside the usual headline/body/logo/circlelines/button edits.

5. LinkedIn post — white version (1080×1080)

Uses a white/light gradient background instead of navy, dark navy text instead of white, and a division-specific color logo instead of the reversed white logo used on the navy designs. Accent color, circlelines, and body copy/headline are otherwise identical to the navy formats. See the Life Sci row above.

6. LinkedIn single-image ad — light version (1200×627)

Light/white-background variant of format 2, using the same layout logic as format 3: color logo instead of reversed-white logo, division accent color on the circle/circlelines/button. Template fix on build: the source file (copied from an older Dataforce-based file) still had a leftover headline reading "FOR DATA" instead of "FOR GAMES", plus a duplicate stacked date/venue text box. Both were corrected on the source before any divisions were built from it.

7. LinkedIn post — light version, "white callouts" style (1080×1080)

A distinct light-background layout — centered large body copy, logo bottom-right, CTA bottom-left, vertical rotated headline text along the left edge, and a shared "BEYOND INTELLIGENCE" tagline top-right (kept identical across all divisions per decision, not division-specific). No circlelines or accent-circle elements exist in this layout. Dataforce is the source template; the other 10 were copied fresh and edited: headline, body copy, accent button fill, and color logo fill.

8. LinkedIn post — dark callouts (1080×1080)

Dark-background counterpart to format 7 (light "white callouts"). Same layout family and page-ID lineage — centered body copy, reversed logo, CTA button, no circlelines/accent-circle element. Games source template originally had leftover Dataforce headline ("FOR DATA") and body copy carried over from an earlier duplication; both were corrected on the source before building the other 10 divisions. The logo element was also fixed from a locked/non-editable native element to a proper editable image frame (same fix pattern as format 4's accent circle) before this format could be built at all — worth checking for on any newly-duplicated master going forward.

9. Email header — dark v1 (800×250)

Same layout logic as the navy LinkedIn ad (format 2): reversed-white logo, division accent color on both the accent circle and CTA button, division circlelines. Games is the source template; the other 10 were copied fresh and edited: headline, body copy, accent circle fill, CTA button fill, circlelines fill, and logo fill.

10. Email header — dark v2 (800×250)

Styled as an article/webinar promo rather than the standard event-headline pattern. The source template's headline/subhead ("GenAI and Machine Translation in Retail Marketing: Industry Leaders Discuss Real-World Success at GlobalLinkNEXT") plus the "BEYOND INTELLIGENCE" tagline, date/venue, and CTA text all stay identical across every division — a deliberate decision (the copy references GlobalLinkNEXT specifically but sits under each division's own logo/accent/circlelines by design). Only three elements are swapped per division: CTA button fill, circlelines fill, and logo fill.

11. Email header — light v1 (800×250)

Light-background counterpart to format 6: standard per-division headline pattern ("THE NEW PRODUCTION ECOSYSTEM FOR [DIVISION]"), color logo instead of reversed-white, division accent on circlelines and CTA button. Games is the source template; sources were confirmed clean before mass-copying.

12. Email header — light v2 (800×250)

Shares the GenAI/webinar-promo copy pattern with format 7 (headline, subhead, tagline, date/venue, and CTA text identical across all divisions). Only three fills swap per division: CTA button, circlelines, and color logo.

13. Email header — light v3 (800×250)

Standard per-division headline pattern, plus a large circular conference-stage hero photo (shared/decorative asset, not customized per division — consistent with the campaign-wide decision to skip character/hero images). Per-division edits: headline text, CTA button fill, circlelines fill, color logo fill.

14. Email header — light v4 / "white v4" (800×250)

GenAI/webinar-promo shared-copy pattern (like formats 7 and 10), but this layout has no circlelines element. Only two fills swap per division: CTA button and color logo. Games source file is titled "GamesNEXT Email Header white v4" in Canva.

15. Email header — dark v3 (800×250)

Same page/element family as format 11 (light v3): standard per-division headline pattern plus the shared conference-stage hero photo. Navy background, so uses the reversed/white logo asset instead of the color logo. Per-division edits: headline text, CTA button fill, circlelines fill, white logo fill.

16. Email header — dark v4 (800×250)

Same page/element family as format 12 (light v4): GenAI/webinar-promo shared-copy pattern, no circlelines element. Navy background, reversed/white logo asset. Only two fills swap per division: CTA button and white logo.

17–19. Advocacy squares — light (1080×1080)

Three social graphics on a white/light background — "I'm attending," "I'm speaking," "we're sponsoring." Games is the source template for all three. Per-division: logo (color version), circlelines (×5, arranged around the headline), accent CTA button fill, and body copy. Built across all 11 divisions.

20–22. Advocacy squares — dark (1080×1080)

Navy counterparts to 15–17, same layout and copy pattern on a dark background with the reversed/white logo. The three Games source files had leftover Dataforce body copy, corrected before any division copies were made. Built across all 11 divisions.

23. Sponsors grid (1200×628)

Per-division sponsor logo grid. No accent circle, circlelines, or CTA button fill in this layout — differs by logo and copy only. The placeholder sponsor logo tiles were confirmed as placeholders and cleared to an empty grid on the Games source file (propagating to all copies) rather than left with stand-in logos, pending real sponsor confirmations.

24–27. Meet the speakers — 3/4/5/6-speaker (1200×628)

Four separate layouts (one source file each) holding 3, 4, 5, or 6 circular headshot placeholders. No accent circle or CTA button fill in any of the four — per-division elements are logo, circlelines (one per headshot), headline, and body copy. All speaker name/title/company placeholders were blanked on each source template from leftover real names (Xbox, Bell Canada, Elevance Health) to a generic FIRST LAST / TITLE – COMPANY convention before any divisions were copied, so every division inherits clean placeholders. Built across all 11 divisions. Media's 5- and 6-speaker copies were built in a later remediation pass after initially being scoped out — see below.

28. Meet the keynote (1200×628)

Single-speaker layout with name/quote/company/title (already generic on the source template, no blanking needed), a large accent circle, and — uniquely to this format — the Games armor character. Per the standing decision to keep that character exclusive to Games, it was deleted from all 10 other divisions' copies, including Media's. Built across all 11 divisions.

Media remediation (formats 26–28)

Media originally shipped with only the 3- and 4-speaker designs (formats 24–25); the 5-speaker, 6-speaker, and keynote formats were scoped out on the assumption that Media's own hero/character square post (format 3) covered its need for a "face" of the campaign. That scoping decision was reversed, and all three were built in a later pass using the same template-copy-and-swap pattern as the other divisions: logo and circlelines (or logo and accent circle, for the keynote) swapped to Media's assets, headline and body copy updated to Media's standard copy, and the Games armor character deleted from Media's keynote copy per the standing rule. Media now has the full 24–28 set, matching every other division.

1. Sponsorship packet (8 pages, letter/A4 proportions)

Multi-page sponsorship prospectus: cover, gradient/tagline page, "Who Attends?" stats page, "The Event" (venue/date/CTA), Past Attendees logo grid, Sponsorship Opportunities (Silver/Gold table), Agreement Terms and Conditions, and a signature page. GlobalLink is the source template (design DAHDGo1c_tU) — cleaned from an older 10-page file down to 8 pages (dropped duplicate USA/EMEA event-location pages and a triple-duplicated event-listing block), and its own logo/color-logo fills were corrected from leftover TransPerfect assets to true GlobalLink assets. Per-division edits: reversed logo (×3, on cover/p2/past-attendees), circlelines (×2, on cover/event page), color logo (×1, on event page), and three text elements on the Agreement Terms page renaming "TransPerfect GlobalLink NEXT" / "GlobalLinkNEXT" to "[Division]NEXT" (no "TransPerfect" prefix). No accent-circle or CTA-button fills in this format. Built across all 11 divisions, including Media.

2. PowerPoint Template (18 pages, 16:9)

Master corporate PowerPoint deck built on the TransPerfect NEXT visual system (division accent, headline suffix, logo lockup, circlelines background, gradient title slides), plus a dedicated closing slide. Games is the source template (18 pages; pages 7–10 have no editable division fields and are skipped). Per-division edits across the other 10 divisions: headline text find/replace on pages 1–2, color logo fill (p2), accent-circle fill (pages 3–6, 11–16), wordmark fill (pages 4, 6, 11, 13, 15, 17), circlelines fill (pages 11–14), and navy-background logo fill (p18, the closing slide). Built and filed for all 11 divisions as of 2026-07-14, each under its own PowerPoints subfolder (see section 9).
Download .pptx links (section 3) are permanently hosted copies, fetched from Canva and stored in this project's own database/storage on 2026-07-15. If a division's deck is edited in Canva afterward, this stored copy will be stale until re-fetched.

7. Element ID reference (all formats, 1–28)

Page IDs and swappable element IDs on the source template for each format, captured directly from the Canva API. Page IDs and per-element IDs are identical across every division's copy of a given format (only the fill/text contents differ), so this table doubles as the reference for editing any division's copy, not just the source template.
Page IDs are not globally unique in this workspace. Canva reuses page IDs across unrelated top-level designs when one was duplicated from another (e.g. formats 2 and 4 share a page ID; formats 6, 7, 9, and 10 share another; formats 11–14 share yet another; and formats 5 and 16–21 happen to share one too). A page ID alone never identifies which design you're looking at — pair it with the source template listed in section 7.
Caution when copying values from the source template: a source template's fill sometimes shows a generic/placeholder asset rather than Games' own registered accent color (e.g. the dark advocacy squares' CTA button shows MAHOu1EAbd0 on the Games source template, not Games' actual accent asset MAHOvDwDvpc). Always pull the target division's asset ID from section 3's registry — never copy whatever asset ID the source template currently displays.

8. Knowledge base

A living reference of everything the NEXT 2026 build team should know — event conventions, division system, formats, workflow rules, and gotchas. New entries auto-append below as the build evolves; team members can also add local notes that persist in this browser.

Naming & identity

  • Event name pattern: [Division]NEXT (e.g. GamesNEXT, LegalNEXT, LifeSciencesNEXT).
  • Master event: TransPerfect NEXT 2026. Shared across 11 divisions.
  • Every division has: full-color logo, reversed (white) logo, monochrome variant, accent color, division subtitle line.
  • Logos stored in shared Dropbox with per-division subfolders — access via the logo modal on any division block.

Division color system

  • TransPerfect & GlobalLink share the core brand blue #13B1F3.
  • Games #A6FA87 · Finance #FF9B70 · Legal #3BBEB6 · Life Sciences #58ED21.
  • Experience #FF5757 · Learn #FFEB66 · Media #EC388A · Digital #C2A3FF · Dataforce #5CE1E6.
  • Accent color drives circle fill, CTA button, and division text across all 28 formats.

Format families

  • Social: Square post, LinkedIn ads (navy / white / light / dark callouts), Story.
  • Print: Sponsorship packet, one-pagers, event signage (8.5×11 & A4).
  • Screens: Event screen imagery / large-screen visuals (16:9, 21:9).
  • Web: Hero banners, email headers, landing tiles.
  • See section 4 for pixel dimensions and section 7 for element IDs.

Canva workflow

  • Permanent design URL: canva.com/design/{design_id}. Short /d/ URLs rotate — don't hard-code them. Do not append /view, /edit, or tracking parameters in BrandHub.
  • Page IDs are not globally unique — always pair a page ID with its source template ID.
  • When editing via API, pull each fill's asset ID from section 3, not from whatever the source template currently displays.
  • Source templates are single-source-of-truth. Division copies inherit element IDs; only fill/text content differs.

Editing conventions

  • Headline: division name in caps, e.g. GAMESNEXT. Body copy: max 2 lines.
  • Date/venue block is shared copy — update it in section 1 first, then propagate.
  • Circlelines and accent-circle are optional per layout (see section 5 note).
  • CTA: consistent verb + destination ("Register now", "See the agenda").

Gotchas & known issues

  • Games source template shows a placeholder fill MAHOu1EAbd0 for the dark advocacy CTA — the real Games accent asset is MAHOvDwDvpc.
